# 后续迭代清单

> 历史快照：本轮针对 1.0.0 / 2f194b4。后续 1.0.1 的修复与原生验证见 [发布记录](../../validation/v1.0.1/README.md)。以下数值及失败记录保留为原始审查证据。

本轮交付的是审查证据与工作顺序，不包含运行代码修复或公开仓库。R01 已经两次原生复现：输入被接受、错误结果提交、第三个方块消失，且一次撤销可恢复。优先级据此更新；仍未验证的风险不应当作已确认缺陷。每个阶段可独立审阅与合入。

| 顺序 | 工作项 | 具体产出与验收 |
| --- | --- | --- |
| 1 | 阻止 R01 错误结果提交 | 按壳体包含关系规范方向，或在无法判断时拒绝歧义输入并完整保留来源。以本次前后 SKP、体积、壳体数及第三方块射线命中验收；成功结果必须为 1072 in³ / 三壳体，拒绝路径必须保留来源。空腔及内岛对照不得退化。 |
| 2 | 修复 F01 入口重入保护 | 只有获得忙碌标记的调用才能释放；第一次执行中连续两次重入均不进入引擎；成功 / 异常后可再次执行；现有基线通过。保留诊断并转为正常回归测试。 |
| 3 | 固化独立原生验收 | 本次 macOS 17 项基线通过，新增 14 项为 13 通过 / 1 缺陷；修复后复跑并保存源代码摘要及结果。继续使用独立空白模型，任何共享启动入口暂停均须协调、记录并原样恢复；不操作他人实例。 |

发布前要求：没有已知“错误结果仍提交并删除来源”的未处理问题；基线和新增的已支持输入回归通过；数值限制写清楚；Windows 宿主若仍未实测，明确标记，不能用 Windows CI 代替。许可证选择、仓库公开及对外发布均不在本轮自动执行范围内。
