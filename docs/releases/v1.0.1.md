超级组合 1.0.1，首个正式开源维护版本，使用 MIT 许可。

### 修复

- 防止混合法线多壳体产生缺失几何的结果：预检独立外壳方向并在提交前检查结果范围，方向歧义或范围不一致时回滚并保留来源和选择。
- 修复重入保护；被拒绝的调用不再清除正在执行的忙碌状态。
- 集中版本定义，按清单打包，排除额外元数据；RBZ 包含项目 MIT 及第三方许可。

### 安装

下载本页 `super-combine-1.0.1.rbz`，在 SketchUp「扩展 → 扩展程序管理器 → 安装扩展」中选择它。SHA256 见 `SHA256SUMS.txt`。

选中同一编辑层级的群组或组件，使用右键、工具栏或扩展菜单中的「超级组合」。成功后可按一次 ⌘Z / Ctrl+Z 恢复来源。离线运行，无其他插件依赖。

### 验证与限制

macOS SketchUp 2026 的原生验证记录位于 `docs/validation/v1.0.1/`。macOS / Windows CI 分别测试纯内核、入口保护、范围校验和可重复打包；CI 不包含 SketchUp 宿主。Windows SketchUp 尚未实机验证。

范围校验是防止错误结果提交的必要检查，不是任意破损模型的修复保证。混合法线、极小面、相切或自交仍可能被拒绝。相离物体不搭桥；组件关联、内层分组和自定义属性会在组合后展开。共享父组件内部编辑仍按 SketchUp 正常联动语义工作。
